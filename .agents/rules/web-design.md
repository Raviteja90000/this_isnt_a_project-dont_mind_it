# Default Anti-Slop Web & App Design Directives

All frontend, web application, and landing page development in this workspace must adhere to the **Anti-Slop Web & App Design Standard** synthesized from **Taste Skill** and **App Designer**:

1. **Concept, Not Theme:** Every interface must embody a tangible, subject-specific real-world metaphor (e.g. physical materials, architectural rhythm, analog instruments). Never use generic SaaS template patterns.
2. **Explore 3 Directions:** Conceptualize three distinct directions (tactile/analog, editorial precision, atmospheric/minimalist) before committing to a final layout.
3. **Strict Cliché Bans:**
   - ❌ No AI purple/blue neon glows or floating blurred blobs.
   - ❌ No centered 3-line headlines with generic pill badges and identical dual buttons.
   - ❌ No symmetrical 3-column feature card rows with generic icons.
   - ❌ No emojis in UI buttons, navigation, or text cards.
   - ❌ Never use `h-screen` for hero sections (use `min-h-[100dvh]`).
4. **Default Dials:**
   - `DESIGN_VARIANCE: 8` (Intentional asymmetry and layout rhythm)
   - `MOTION_INTENSITY: 6` (Spring physics and tactile interactions)
   - `VISUAL_DENSITY: 4` (Generous negative space, breathing room)
5. **One Live Thing:** Every landing page must include one real, interactive, high-value mechanism (configurator, calculator, interactive visual specimen).
