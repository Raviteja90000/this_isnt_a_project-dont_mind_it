# Default Anti-Slop Website & Interface Design System

> **Mandatory Workspace Guideline:** This document defines the unconditional default standard for all web development, UI/UX design, landing pages, and frontend implementation within this workspace. It synthesizes the philosophies of **Taste Skill** (by Leon Lin) and **App Designer** (by Tobia Donadon) to ensure no interface looks generic, templated, or "AI-generated".

---

## 1. Core Design Philosophy: "Concept, Not Theme"

1. **Rooted in the Subject, Not the Category:**
   - Every website or app must stem from a real concept belonging strictly to the subject—never from generic category templates.
   - **The Subject Inventory:** Before writing markup or styling, identify 8–12 tangible artifacts unique to the subject (its physical materials, architectural shapes, rituals, real numbers, geography, typography on historic signs, ticket/receipt/menu artifacts).
   - **The Competitor Test:** If a headline, visual metaphor, or layout device could be swapped into a competitor's site without feeling out of place, **reject it**.

2. **Three Directions, Then One:**
   - Never settle on the first average idea generated by the model.
   - Conceptualize 3 distinct creative directions for the core interface (e.g., editorial documentary, technical precision bento, tactile physical artifact). Select the one that uniquely serves the subject.

3. **Active Baseline Dials:**
   - `DESIGN_VARIANCE: 8` (1 = Rigid 12-col symmetry, 10 = High-agency intentional asymmetry)
   - `MOTION_INTENSITY: 6` (1 = Pure static, 10 = Cinematic spring physics)
   - `VISUAL_DENSITY: 4` (1 = Art gallery / airy whitespace, 10 = Compact cockpit)

## 2. Banned "AI Slop" Anti-Patterns (Strictly Prohibited)

The following clichés instantly reveal automated, thoughtless generation and are **strictly banned**:

* ❌ **The "AI Purple/Blue" Glow ("The Lila Ban"):** No neon cyan/indigo gradients, floating blurry color blobs, or purple glow box-shadows.
* ❌ **Centered 3-Line Cliché Hero:** No centered headline + generic eyebrow pill badge + generic subtext + 2 centered rounded pill buttons. Use asymmetric split layouts, bold editorial left-alignment, or bespoke compositional structures.
* ❌ **Symmetrical 3-Card Feature Rows:** No 3 identical rounded rectangular cards with centered icon badges, bold title, and 2-sentence filler descriptions. Use varied aspect ratios, bento hierarchy, border-delimited sections, or typographic lists.
* ❌ **Default Generic Typography:** No uninspired `Inter`, `Arial`, or system `Roboto` fallbacks for premium/creative projects. Use characterful typography (e.g., `Geist`, `Cabinet Grotesk`, `Outfit`, `Satoshi`, `Plus Jakarta Sans`, `Newsreader`, `Fraunces`).
* ❌ **Card Overuse & Box Wrapping:** Do not wrap every piece of content in a border-and-shadow card. Let data breathe using generous whitespace, `divide-y`, clean hairlines, or editorial columns.
* ❌ **Banned Emojis:** NEVER use emojis as icons or bullet points in UI components. Use clean SVG primitives, Phosphor Icons, or Radix Icons.
* ❌ **Mobile Viewport Flaws:** NEVER use `h-screen`. ALWAYS use `min-h-[100dvh]` to eliminate mobile address-bar jumpiness.

## 3. High-Agency House Style Rules

1. **Typographic Hierarchy & Confident Scale:**
   - Hero / Display headlines: `text-5xl md:text-7xl lg:text-8xl font-semibold tracking-[-0.04em] leading-[0.95]`. Keep headlines concise (target ≤ 32 characters, ≤ 2 lines).
   - Monospace or small caps for metadata/labels: `font-mono text-[0.72rem] uppercase tracking-[0.14em] text-neutral-500`.
   - Body copy: `text-base sm:text-lg text-neutral-600 leading-relaxed max-w-[65ch]`.

2. **Color Palette & Materiality:**
   - **Ground & Ink:** Choose authentic backgrounds (warm parchment `#faf8f5`, stone `#f5f4f0`, deep obsidian `#0b0c10`, or ink black `#0e0e0e`) instead of harsh `#000000` or sterile `#ffffff`.
   - **Accents:** Maximum 1–2 purposeful accent colors calibrated below 80% saturation. The colors should reflect the subject's real-world environment (terracotta, slate, forest pine, raw brass).
   - **Tactile Materiality:** When using glass or panels, use high-fidelity inner borders (`border-white/10`) and subtle inset highlights (`shadow-[inset_0_1px_0_rgba(255,255,255,0.1)]`) instead of blurry generic dropshadows.

3. **Layout & Composition:**
   - CSS Grid with fractional units (`grid-cols-1 md:grid-cols-[1.2fr_0.8fr]`) over complex flexbox math.
   - Bold negative space and intentional asymmetry that collapses cleanly to a single-column layout on mobile viewports (< 768px).

4. **"One Live Thing":**
   - Every landing page or interface should include **one real, interactive mechanism** derived from the core idea (e.g., a real interactive simulator, material selector, live schedule tracker, or interactive calculation). Not a gimmick—a useful, responsive tool.

5. **Fluid Motion & Micro-Interactions:**
   - Use spring physics (`stiffness: 120, damping: 20`) for tactile feedback.
   - Micro-interactions: subtle active states (`active:scale-[0.98]`), delicate border-color transitions, and staggered loading cascades.

---

## 4. Pre-Flight Review Checklist (Self-Critique)

Before finalizing any frontend or UI design, evaluate the work against this rubric:
- [ ] Does this interface have a distinct visual soul, or does it look like a generic theme?
- [ ] Is there at least one non-standard compositional choice (asymmetry, bold scale, unexpected layout)?
- [ ] Did I eliminate all banned clichés (purple gradients, generic 3-card grids, emojis, centered pills)?
- [ ] Does the headline fit within two lines without awkward line breaks on mobile?
- [ ] Is the design fully responsive, avoiding horizontal overflows on 375px screens?
